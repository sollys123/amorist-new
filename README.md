# Amorist

这是我的乙女游戏个人网站，主要用于整理和展示游戏收藏、游玩记录及相关创作。

如果你也是日乙玩家，想制作属于自己的个人网站，也可以从这个项目中获得一些思路，借鉴和学习其中的部分功能、信息组织方式与页面布局。但请不要整站照抄，也不要完全模仿我的配色、视觉设计或整体风格，请根据自己的内容与审美进行创作。

## 网站内容

本站主要收录以下内容：

- 乙女游戏收藏与游玩记录
- 作品及角色相关评价
- 通关感想与个人整理
- 与乙女游戏相关的创作内容

部分页面可能包含剧情、角色路线及结局相关剧透，浏览时请自行注意。

## 使用说明

本站主要用于展示个人的乙女游戏收藏、游玩记录及相关创作，同时开放部分制作工具供访客使用。

目前公开提供的功能包括：

- 乙女游戏 REPO 制作
- 排名、评分及其他表格制作
- 图片导出

本站不提供账号、云端存储或跨设备同步功能。使用上述工具时，请在离开页面前自行导出或保存制作结果。

推荐使用最新版 Chrome、Edge、Safari 或其他现代浏览器访问。不同设备及浏览器下的显示效果可能略有差异。
